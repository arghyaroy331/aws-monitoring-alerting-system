Infrastructure Components

Core services used to provision and monitor the application host.

Terraform

Defines AWS networking, security rules, IAM permissions, and EC2 infrastructure as code.

Amazon EC2

Runs Amazon Linux 2023 and the Nginx web server in the Mumbai region.

Amazon CloudWatch

Collects and evaluates CPU, memory, and disk usage metrics through metrics and alarms.

Amazon SNS

Delivers email notifications when configured alarm actions are triggered.

Monitoring Coverage

Resource metrics are visualized in the CloudWatch dashboard.

CPU Utilization

Metric: CPUUtilization

Alarm threshold: above 70%.

Memory Usage

Metric: mem_used_percent

Alarm threshold: above 80%.

Disk Usage

Metric: disk_used_percent

Alarm threshold: above 80%.

Live monitoring: Current metrics and alarm states are available in the AWS CloudWatch console. This webpage is a project overview, not a live metrics dashboard.

Security & Operations

Access Controls

SSH restricted to an administrator IP, with Systems Manager access available for administration.

Instance Protection

IMDSv2 required and encrypted root storage configured.

Cost Awareness

Resource usage and AWS billing require regular review; budget alerts do not automatically stop services.

Project status: Terraform provisioning, EC2 hosting, CloudWatch metrics and alarms, dashboard, and the CPU-to-SNS email notification test are implemented. GitHub Actions CI/CD and Lambda-based remediation remain planned enhancements.
